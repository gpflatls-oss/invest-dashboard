# 투자관리 대시보드

대체투자 자산군별 뉴스와 시장지표를 한 화면에 모아 보는 정적 대시보드입니다.
빌드 도구나 서버 없이 `index.html` 하나로 동작합니다.

다루는 자산군은 Private Equity, Private Debt, Venture Capital,
해외 부동산, 해외 인프라, 국내 부동산, 국내 인프라 일곱 가지입니다.
환율·금리·주가지수·원자재는 이 자산군들을 읽기 위한 배경 지표로 함께 띄웁니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 전체. 의존성 없는 순수 HTML/CSS/JS |
| `data.js` | 수집 결과. `window.DASHBOARD_DATA` 하나만 정의합니다 |
| `refresh.ps1` | 수집 스크립트. `data.js` 를 새로 만듭니다 |
| `갱신.bat` | 위 스크립트를 더블클릭으로 실행하기 위한 배치 파일 |
| `.github/workflows/refresh.yml` | GitHub Actions 로 주기 수집 후 커밋 |

## 로컬에서 갱신하기

`갱신.bat` 을 더블클릭하거나, PowerShell 에서 아래를 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\refresh.ps1
```

Windows 기본 PowerShell 5.1 만 있으면 되고 추가 설치는 필요 없습니다.
기간이나 기사 수를 바꾸려면 인자를 넘기세요.

```powershell
.\refresh.ps1 -NewsDays 14 -NewsPerClass 20
```

## 자동 갱신

`.github/workflows/refresh.yml` 이 평일 30분 간격(KST 09:05~18:35)과
미국장 시간대(KST 22:05 / 06:05)에 수집을 돌리고, 값이 바뀌었을 때만 `data.js` 를 커밋합니다.
Actions 탭에서 수동 실행도 됩니다.

GitHub 의 예약 실행은 러너가 붐빌 때 수 분에서 수십 분 밀릴 수 있고,
저장소에 60일간 아무 활동이 없으면 자동으로 비활성화됩니다.

## 데이터 출처

- 환율·국내시장금리·유가·금: 네이버 금융 시장지표 JSON API (하나은행·금투협·한국은행·은행연합회·NYMEX·COMEX·KRX 금시장·오피넷·ICE 고시 기준)
- 달러/엔: 야후 파이낸스 (네이버 API 에 없음)
- 국고채 3·5·10년: 네이버 금융 채권 시세 (체결 기준)
- 미국 기준금리·SOFR: 뉴욕연방준비은행 마켓 API (기준금리는 EFFR 고시 레코드에 붙어 오는 연준 목표범위)
- 미국 국채 2·10·30년, 독일 국채 10년: 네이버 금융 채권 시세 (체결 기준 · 각 시장 현지시간)
- 미국 장단기 금리차(10년−2년), 한미 10년 금리차(국고채−미국 국채): 위 값에서 계산
- 주가지수: 네이버 금융 지수 시세 (한국거래소 및 각 해외 거래소)
- 뉴스: Google 뉴스 검색. 자산군마다 쿼리를 여러 개 던진 뒤
  쿼리별 후보를 번갈아 뽑아 한 사건이 목록을 독식하지 않게 하고,
  제목을 두 글자 단위로 비교해 같은 사건을 다룬 중복 기사를 걸러냅니다.
  국내 매체는 한국어판에서, 해외 매체는 영어판에서 받아 제목을 한국어로
  번역해 함께 싣고 `해외·번역` 표시를 붙입니다 (원문 제목은 마우스를 올리면 보입니다).

### 해외 기사 번역에 관한 주의

번역은 `translate.googleapis.com` 의 **비공식 엔드포인트**를 씁니다. API 키가 필요 없는 대신
언제든 막히거나 호출이 조여질 수 있습니다. 번역에 실패한 기사는 영어 제목이 섞이지 않도록
아예 싣지 않고, 실패 건수만 수집 경고에 남깁니다. 해외 기사가 갑자기 0건이 된다면
이 엔드포인트를 먼저 의심하세요.

기계번역이라 업계 용어가 어색하게 나올 수 있어 자주 나오는 몇 개(`private credit` →
사모대출 등)만 `$GLOSSARY` 에서 바로잡습니다.

영어판 검색에는 국내 언론의 영문판도 잡힙니다. 이걸 번역하면 한국어 → 영어 → 한국어
왕복이 되어 고유명사가 망가지므로(`한국부동산원` → `한국부동산위원회`) `$KOREAN_OUTLETS`
목록으로 제외합니다.

금리는 %p 변화가 의미 있는 값이라 비율을 표시하지 않습니다.

### 네이버 시장지표는 JSON API 로 받습니다

`finance.naver.com/marketindex/` 가 2026년 9월에 Next.js 로 개편되면서 HTML 에 값이 실려
오지 않게 됐습니다(전부 클라이언트 렌더링). 그래서 그 화면이 쓰는 API 를 직접 읽습니다.

```
https://api.stock.naver.com/marketindex/{category}                       목록
https://api.stock.naver.com/marketindex/{category}/{code}/prices?page=1   일별 시세
```

category 는 `exchange` / `energy` / `metals` / `agricultural` / `domesticInterest` / `bond` 이고
항목은 `reutersCode` 로 고릅니다 (`refresh.ps1` 의 `$MI_ITEMS`). 표시명은 네이버가 바꿀 수
있지만 코드는 고정이라 이력이 끊기지 않습니다.

개편 전 화면과 기준이 달라진 항목:

- **국내 금** — 신한은행 고시(원/g)에서 **KRX 금시장 1g 종가**로 바뀌었습니다. 이전 3주치
  이력은 기준이 달라 지우고 KRX 값으로 2023년부터 다시 채웠습니다.
- **달러/엔** — 이 API 에는 원화 교차환율만 있어 야후 파이낸스(`JPY=X`)로 받습니다.
  백필 이력과 같은 소스라 차트가 이어집니다.
- **금리** — 값은 같은 고시치이고 고시일이 함께 와서 이력 날짜가 고시일로 찍힙니다.

같은 API 의 `/prices` 로 국내 금리·국내 금·휘발유 이력도 받을 수 있어, ECOS 키 없이도
`backfill_history.ps1` 이 모든 지표를 백필합니다.

### 국고채 만기별 수익률

국내시장금리 목록(`domesticInterest`)에는 국고채가 없습니다. 모바일 채권 화면이 쓰는
`api.stock.naver.com/marketindex/bond/{코드}` 에서 받습니다. 코드는 로이터 형식입니다.

| 만기 | 코드 |
|---|---|
| 1년 | `KR1YT=RR` |
| 2년 | `KR2YT=RR` |
| 3년 | `KR3YT=RR` |
| 5년 | `KR5YT=RR` |
| 10년 | `KR10YT=RR` |
| 20년 | `KR20YT=RR` |
| 30년 | `KR30YT=RR` |

지금은 3·5·10년만 싣습니다. 다른 만기를 넣으려면 `$BOND_TENORS` 에 줄을 추가하면 됩니다.
해외 국채도 같은 API 를 씁니다 (`$US_BOND_TENORS`, `$EU_BOND_TENORS`). 지금은
`US2YT=RR`, `US10YT=RR`, `US30YT=RR`, `DE10YT=RR` 이고 `US3MT`, `US5YT`, `JP10YT`, `GB10YT` 등을
같은 형식으로 추가할 수 있습니다.

금투협 최종호가수익률과 달리 이 API 는 **체결 기준**이라 값이 조금 다릅니다.
3·5·10년을 모두 체결 기준으로 통일해 싣습니다.

### 해외 금리

미국 기준금리와 SOFR 은 뉴욕연은 마켓 API(`markets.newyorkfed.org/api/rates/…/last/2.json`)에서
받습니다. 매 영업일 아침(미국 동부시간) 전날 값을 고시하는데, EFFR 레코드에는
그날 적용된 연준 목표범위(`targetRateFrom` / `targetRateTo`)가 붙어 옵니다. 키가 필요 없고
연준 공식 자료입니다. FRED 도 같은 값을 주지만 이 PC 에서는 타임아웃이 잦아 쓰지 않았습니다.

SOFR 은 달러 사모대출·레버리지론의 변동금리 기준이라 Private Debt 를 읽을 때 봅니다.
장단기 금리차(10년−2년)는 음수면 역전이고, 한미 10년 금리차(국고채−미국 국채)는 해외 자산
환헤지 비용·자금 흐름의 배경입니다. 두 금리차는 `New-SpreadMetric` 이 원천 지표에서 빼서
만들며 값·등락 모두 %p 입니다. 국고채 10년은 시장지표가 실패해도 채권 API 로 따로 받아
한미 금리차를 계산합니다.

타일에는 관행대로 `3.50~3.75` 범위로 표시하고 EFFR 은 비고에 붙입니다. 범위 문자열은
숫자가 아니라서 이력에는 `hist_value`(목표범위 상단)를 따로 실어 `FEDFUNDS` 코드로 쌓습니다.
전일대비는 전 영업일 목표범위와의 차이라 FOMC 다음 날에만 0 이 아닙니다.

### 회사채 등급 표기

국내시장금리의 회사채(3년)는 금융투자협회가 고시하는 **무보증 3년 AA-**
최종호가수익률입니다 (API 코드 `KFIA103009`. 같은 목록에 BBB- `KFIA103010` 도 있습니다).

표시되는 수치는 고시·체결 시점 기준의 참고용 정보입니다.
실시간 호가가 아니며 투자 판단의 근거로 쓰기에는 지연과 오차가 있을 수 있습니다.
